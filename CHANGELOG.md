# Changelog

## 1.0.1 — 2026-10-31

- Three-round Daily Runs with six guesses per round, transparent scoring, rule-by-rule feedback, and optional Nudges.
- One authoritative 22-rule engine accepting any dictionary word that satisfies every constraint.
- Offline English dictionary, common-word quality list, and a validated 396-day schedule of 1,188 puzzles.
- Endless practice, validated friend challenge links, independent archive replays, device-local statistics, and 12 earned achievements.
- Spoiler-free text sharing and branded image exports.
- Versioned progress, multi-tab reconciliation, damaged-save recovery, backup import/export, light/dark themes, higher contrast, reduced motion, and optional sound.
- Installable offline app with deliberate update activation, responsive editorial design, and hash routing under `/Loophole/`.
- Automated logic, content, browser, and accessibility checks; GitHub Pages and tested semantic-release workflows.

Publication is tracked by GitHub Actions and Releases, not by this changelog. A version becomes released only after its matching tag passes the release workflow.
