## A quieter Loophole, with a better Warm-Up

The complete interface now follows the approved 18-screen Quiet Interface Exploration: dark neutral surfaces, self-hosted DM Sans and Instrument Serif, a centered puzzle stage, thin separators, restrained accents, and simple rectangular controls. The orange homepage ornament is absent. Every existing screen and mobile navigation has been redesigned, including results, failure states, practice, friend challenges, archive, statistics, achievements, tutorial, settings, and recovery.

### Difficulty that means more than the number of rules

The original audit found 137 of 396 Warm-Ups forced words longer than six letters. The new model measures rule complexity and interaction, word length, solution availability, vocabulary familiarity, and unusual letters.

- Warm-Up: three simple rules; 4–6-letter words; 40–250 common solutions; several highly familiar answers.
- The Stretch: four moderate rules; 4–7-letter words; 15–70 common solutions.
- The Loophole: five interacting rules; 4–9-letter words; 5–30 common solutions; recognizable answers remain available.

The new immutable schedule contains 366 days / 1,098 puzzles, beginning November 1, 2026. The original 1,188 puzzles are retained unchanged. Historical date mappings and existing saved runs remain intact. Practice uses the calibrated pool immediately. Nudges now reveal an informative verified position when a first-letter clue would merely repeat a visible rule.

### Compatibility and quality

Scoring formulas, attempts, achievement conditions, completion streaks, and storage schema are unchanged. Existing light/dark/system preferences are preserved; new players receive the approved dark appearance. Existing version-1 friend links retain their original scoring tier; version-2 links use the new difficulty estimate.

Offline caching includes the self-hosted fonts and both content versions. Update installation revalidates HTTP-cached HTML, avoiding an old-interface cache trap while keeping the current puzzle open until activation. The release workflow verifies type checking, lint, logic tests, every retained/new puzzle, a production build, browser gameplay, mobile layouts, and accessibility before publishing. See `docs/difficulty-report.md` for the audit and nine validated examples and `docs/visual-verification.md` for comparisons to all 18 exports.

Difficulty timings have not been validated in a human playtest; the model establishes objective content properties, not guaranteed solving times.
